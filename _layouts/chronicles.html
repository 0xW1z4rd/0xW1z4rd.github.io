Classified DOC-001
OSCP Offensive Security Certified Professional Completed
Difficulty HIGH
Duration 90 DAYS
Issuer Offensive Security
Focus AD • Privesc • Pivoting
Context

The OSCP was the first major milestone in the offensive path — a 24-hour proctored examination forcing a complete shift from theoretical knowledge to real-world execution under pressure. The PWK lab environment exposed the full breadth of Active Directory exploitation, privilege escalation chains, and pivoting across isolated network segments.

Preparation Arsenal
  • TJnull's OSCP preparation list — 80+ machines
  • Custom enumeration scripts and checklists
  • Buffer overflow methodology — systematic approach
  • Active Directory attack chains via BloodHound
  • HackTheBox Pro Labs Offshore for AD depth
Lessons Extracted
  • Enumeration depth beats exploit breadth — always
  • Time management is an exam skill as much as a hacking skill
  • Methodology over tooling: tools fail, process doesn't
  • Document everything during the lab — not after
  • A failed machine is information, not a defeat
Classified DOC-002
eWPTX eLearnSecurity Web Penetration Tester eXtreme Completed
Difficulty HIGH
Duration 60 DAYS
Issuer INE Security
Focus Web • API • Injection Chains
Context

After OSCP, the eWPTX pushed deeper into advanced web exploitation — beyond OWASP Top 10 checklists into chained vulnerabilities, filter bypass engineering, and custom payload development. The examination requires building functional exploit chains against hardened web applications, demanding both precision and creativity.

Preparation Arsenal
  • PortSwigger Web Security Academy — all advanced labs
  • Custom Burp Suite extension workflows
  • Payload mutation and WAF bypass research
  • API security testing — REST and GraphQL attack surfaces
  • Manual SQL injection — beyond sqlmap
Lessons Extracted
  • Web vulnerabilities rarely live in isolation — chain them
  • Understand the underlying protocol before reaching for a tool
  • Filter bypass is an art: know why each character is filtered
  • API attack surface is massively underestimated in real engagements
  • Speed comes from deep pattern recognition, not checklists
Classified DOC-003
OSWE Offensive Security Web Expert Completed
Difficulty EXPERT
Duration 90 DAYS
Issuer Offensive Security
Focus Source Code • Auth Bypass • Custom Exploits
Context

The AWAE course and OSWE exam represent a paradigm shift: moving from black-box exploitation to whitebox source code review. Instead of probing from the outside, the challenge is to read application source code, trace data flows from user input to dangerous sinks, and write fully automated Python exploit scripts from scratch — no manual interaction allowed during the exam.

Preparation Arsenal
  • PHP, Python, Java — reading code, not just writing it
  • Data flow tracing: user input → dangerous sinks
  • Exploit automation in Python — timing, threading, reliability
  • Authentication bypass at the code level
  • Second-order vulnerability identification methodology
Lessons Extracted
  • Source code is the ground truth — read it before guessing
  • Authentication logic is almost always broken somewhere
  • Automation separates researchers from script kiddies
  • Second-order flaws are everywhere — trace data persistence
  • The exam is a mental endurance test as much as a technical one
Classified DOC-004
OSEP Offensive Security Experienced Penetration Tester Completed
Difficulty EXPERT
Duration 120 DAYS
Issuer Offensive Security
Focus Evasion • C2 • AD • Lateral Movement
Context

PEN-300 and the OSEP exam represent the pinnacle of red team certification: operating against defended environments with active endpoint protection, simulating sophisticated threat actors across complex Active Directory infrastructures. The focus is on evasion at every layer — from initial access through to command-and-control and data exfiltration — requiring custom tooling development throughout.

Preparation Arsenal
  • C# weaponization — custom loaders, shellcode runners
  • AMSI bypass research — patching and reflection techniques
  • Process injection and hollowing for stealth execution
  • Phased attack planning across segmented AD environments
  • OPSEC discipline — minimal footprint, maximum impact
Lessons Extracted
  • AV evasion is behavioral — signatures are the last layer to beat
  • Custom tooling is a force multiplier; known tools are signatures
  • OPSEC mindset must be present from the first beacon, not after
  • Segmented AD requires patient enumeration before moving laterally
  • Red teaming is storytelling — document the narrative as you operate
